# P2 — Voix & musique

Status: IN REVIEW

## Goal
Verrouiller une narration française engagée et un bed musical original qui soutiennent le pilote sans nuire à la compréhension.

## Voix
- style: `crisp`
- direction: engagée, curieuse, complice
- narration dominante dans le mix
- aucun ton professoral ou surjoué

## Musique
- originale, générée pour le pilote
- 75.05 s
- 108 BPM
- cycle harmonique C → Am → F → G
- pad doux + plucks + petites ponctuations de transition

## Mix canonique v1
- voix: 0 dB référence
- musique sous voix: -22 dB
- transitions: jusqu'à -16 dB
- cible: -16 LUFS, true peak -1 dB

## Human gate
P2 ne peut pas être mergé sur critères techniques seuls. Il faut valider à l'oreille :
1. engagement de la voix ;
2. clarté et rythme ;
3. musique suffisamment présente mais non distrayante ;
4. cohérence globale pour 6–9 ans.
