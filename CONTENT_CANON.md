# Pourquoi ? — Content Canon

Status: CANONICAL
Version: 0.1

## Audience
Âge de référence : 7 ans.

## Règle centrale
Une vidéo doit répondre à une seule question avec une seule idée principale clairement mémorisable.

## Structure canonique
1. Hook — 0 à 5 s
2. Mise en contexte — 5 à 15 s
3. Explication — 15 à 50 s
4. Fait surprenant / conséquence — 50 à 65 s
5. Mini-défi / conclusion — 65 à 90 s

## Style de langue
- Français naturel et oral.
- Phrases courtes.
- Vocabulaire concret.
- Termes difficiles expliqués immédiatement.
- Pas de jargon inutile.
- Pas de ton professoral.
- Humour léger autorisé s'il ne brouille pas l'explication.

## Fact-check
Toute affirmation importante doit être :
- sourcée ;
- compatible avec le consensus scientifique ou historique établi ;
- reformulée sans déformer la source.

Pour un sujet controversé ou incertain :
- signaler l'incertitude ;
- éviter les formulations absolues ;
- ne pas fabriquer une réponse simple si la réalité ne l'est pas.

## Sources
Préférence :
1. institutions scientifiques / publiques ;
2. musées, universités, organismes éducatifs reconnus ;
3. publications ou ouvrages de référence ;
4. sources secondaires fiables pour compléter.

## Interdits
- Copier un script existant.
- Reprendre une mascotte ou identité visuelle protégée.
- Inventer des faits pour rendre l'histoire plus amusante.
- Demander explicitement à l'enfant de cliquer de manière manipulatrice.
- Présenter publicité ou placement comme contenu pédagogique.

## Checklist script
- [ ] La question est comprise en moins de 5 secondes.
- [ ] La réponse principale tient en une phrase.
- [ ] Le script est compréhensible à 7 ans.
- [ ] Chaque mot technique utile est expliqué.
- [ ] Les faits critiques sont sourcés.
- [ ] Une scène correspond à une idée visuelle claire.
- [ ] La conclusion renforce la réponse initiale.
