# Pilot — Research evidence — Pourquoi le ciel est-il bleu ?

Date de vérification : 2026-08-21

## Sources primaires / institutionnelles

### S1 — NASA Space Place
URL : https://spaceplace.nasa.gov/blue-sky/en/

Éléments retenus :
- la lumière solaire paraît blanche mais contient les couleurs visibles ;
- les longueurs d'onde bleues sont plus courtes que les rouges ;
- les molécules de l'atmosphère diffusent la lumière bleue dans toutes les directions ;
- lorsque le Soleil est bas, la lumière traverse davantage d'atmosphère et davantage de bleu est diffusé avant d'atteindre l'observateur.

### S2 — NOAA NESDIS
URL : https://www.nesdis.noaa.gov/about/k-12-education/atmosphere/why-the-sky-blue

Éléments retenus :
- les gaz et particules de l'atmosphère diffusent la lumière solaire ;
- le bleu et le violet sont fortement diffusés ;
- l'œil humain est moins sensible au violet et une partie du violet est absorbée dans la haute atmosphère ;
- les couchers de soleil apparaissent plus rouges lorsque les courtes longueurs d'onde sont davantage diffusées sur le long trajet atmosphérique.

### S3 — NASA Science glossary
URL : https://science.nasa.gov/universe/glossary/

Élément retenu :
- définition institutionnelle de la diffusion de Rayleigh : les molécules d'air diffusent davantage les courtes longueurs d'onde, notamment le bleu, que les longueurs d'onde rouges.

## Décision pédagogique

Pour 7 ans, le script n'introduit pas le terme « diffusion de Rayleigh » dans la narration principale. Le mécanisme est expliqué visuellement avec des molécules d'air et des rayons colorés. Le terme pourra apparaître plus tard dans une fiche parent/enseignant.
