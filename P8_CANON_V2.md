# P8 — Canon visuel V2

## Décision
La chaîne `Pourquoi ?` adopte une identité **100 % sans personnage**.

Direction retenue : **Atelier créatif en collage papier / hand-drawn**.

Cette direction remplace le branding avec mascotte pour toutes les nouvelles surfaces de marque : intro, outro, miniatures, bannière, écrans de fin et fonds génériques.

## Logo
- Nom : `Pourquoi ?`
- Construction : lettres découpées / papier texturé, irrégularités volontaires, superposition légère et ombres papier discrètes.
- Point d’interrogation : élément iconique central, immédiatement reconnaissable.
- Pas de personnage, visage ou silhouette humaine.

## Tagline
`1 question • 1 réponse`

## Palette canonique
- Bleu électrique : `#2563EB`
- Jaune tournesol : `#FFC62E`
- Corail vif : `#FF6B6B`
- Aqua curieux : `#2ECFCB`
- Crème doux / papier : `#FFF4E1`
- Bleu nuit d’accent : `#123B78`

## Matières et textures
- papier déchiré
- papier découpé
- carton léger
- crayon / feutre / craie
- ruban adhésif papier
- quadrillage de cahier ponctuel
- ombres artisanales légères

Aucun rendu plastique 3D glossy comme langage principal.

## Formes récurrentes
- `?`
- nuages découpés
- soleil dessiné
- étoiles papier
- bulles de dialogue
- ampoule
- loupe
- planète / atome / fusée selon sujet
- traits de crayon, flèches, zigzags, soulignements

## Motion canon
Le mouvement doit ressembler à un atelier qui prend vie :
1. éléments papier qui glissent / tombent / se collent ;
2. légère rotation imparfaite ;
3. pop avec overshoot très court ;
4. trait de crayon qui se dessine ;
5. bande adhésive qui se pose ;
6. déchirure / page flip comme transition ;
7. micro-parallaxe entre couches de papier.

Rythme : joyeux, vif, lisible, jamais frénétique.

## Miniatures
- titre court, 3 à 6 mots maximum ;
- mot-clé principal en grand ;
- contraste bleu / crème / jaune / corail ;
- 1 symbole scientifique ou visuel lié à la question ;
- gros `?` comme hook visuel possible ;
- papier déchiré et couches en profondeur ;
- aucun personnage.

## Intro V2
Durée cible : 2–3 s.
Storyboard canon :
1. un `?` en papier apparaît ;
2. les couches colorées s’assemblent rapidement ;
3. le logo `Pourquoi ?` se construit ;
4. la bande `1 question • 1 réponse` se colle ;
5. sortie par déchirure / zoom papier vers l’épisode.

## Outro V2
Durée cible : 5–8 s.
- 2 zones vidéo en papier découpé ;
- 1 zone abonnement ;
- logo `Pourquoi ?` ;
- CTA simple ;
- mêmes textures / couleurs / jingle que l’intro ;
- aucun personnage.

## Ton
Curieux • créatif • éducatif • chaleureux • ludique • clair • artisanal-premium.

## Interdits
- personnage récurrent ;
- mascotte humaine ;
- rendu générique corporate ;
- glassmorphism ;
- 3D plastique brillante dominante ;
- surcharge d’éléments ;
- texte long sur miniatures ;
- ombres lourdes ou photoréalisme.
